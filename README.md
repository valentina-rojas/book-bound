# Book Bound

Juego desarrollado por Emilia Güll, Sol Romero y Valentina Rojas dentro de la materia de Taller de Diseño de Juegos 4.

Book Bound es un juego 2D en primera persona donde sos el encargado de atender y gestionar una antigua biblioteca, en la cual sus clientes son criaturas mágicas como brujas, magos, hadas y otras entidades místicas que buscan conocimiento.
